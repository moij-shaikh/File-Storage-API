# File Storage API 

A backend API for Storing File like Images , Text file , Videos etc Online , Build with Python , Fastapi and supabase.

#Features
- User registration and login
- JWT authentication
- Email verification
- Database migrations
- Antivirus support

# Tech Stack
- Python
- Fastapi
- Postgresql
- Alembic
- Supabase
- Redis
- JWT
